
# 📘 File-by-File Memory Statements

---

# 1️⃣ `bidirectional_bfs.py`

**Sentence**

> This file exists because the system must compute the shortest path between two users efficiently, it talks to the `GraphDatabase` to fetch neighbors, and improves pathfinding performance by reducing the search space using bidirectional BFS.

**What it controls**

* Core algorithm
* Shortest path logic
* Search efficiency

* Connections
* Neighbor queries

# 3️⃣ `sharding.py`

* Query acceleration
